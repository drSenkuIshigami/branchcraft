# Git Workbench — Design Documentation

This directory contains the primary design documents and architectural contracts established for Git Workbench:

- `DATA_MODEL.md`: Core data structures and serializable entities shared between Rust and TypeScript.
- `IPC_CONTRACT.md`: Tauri IPC commands, typing, parameters, return values, and safety levels.
- `COMMAND_ALLOWLIST.md`: Allowed Git subcommands and argument validation patterns.
- `SAFETY_POLICY.md`: 5-tier operation risk model, backup policies, and runbooks.
- `TEST_PLAN.md`: Phased test plans, manual checklists, and automated test strategies.

*Note: These documents are created in Step 4 and will evolve incrementally by phase.*
